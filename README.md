# The Final Trading Bot V5

V5 supports PAPER and a guarded local LIVE mode for SPY 0DTE. LIVE startup requires credentials from exactly `~/Documents/live.env`, an authenticated account response from `https://api.alpaca.markets`, a non-PAPER active account, clear LIVE authority, and the existing runtime guards. PAPER credentials continue to come from `~/Documents/paper.env`; PAPER and bridge tools remain bound to PAPER. LIVE has no automatic start or scheduler path. The near-close SELL escalation requirement is still unresolved, so LIVE use remains blocked.

The runtime coordinates the 30-second breakout signal, option selection and entry, and per-fill position management. Any print above the 30-second high or below the 30-second low is a breakout (an optional `breakoutMarginCents` / `breakoutRangeFraction` filter exists but is off; it was tested LIVE on 2026-10-06 and entered at the end of sweeps instead of the start of moves); FILL ledger events record the triggering excess and range. Accepted OPRA quotes and exit decisions (anchor, floor set/raise, floor/stop latch) are appended to `state/<mode>-accounts/<hash>/telemetry-<ET date>.jsonl`. Alpaca providers supply the market calendar, option contracts and quotes, SIP trades, OPRA quotes, and broker order updates. Strategy sizing remains limited to $481.63 capital and one contract per entry; the daily entry stop is 10% of DAY_START capital measured from the day's realized high-water mark.

Account-scoped continuity and ledgers are stored under gitignored `state/paper-accounts/<account-hash>/` and `state/live-accounts/<account-hash>/`. PAPER credentials are loaded into memory from `~/Documents/paper.env`.

To explicitly start a local LIVE run, use `npm run live`. LIVE keys are never sourced from the PAPER file or process environment. The LIVE file accepts its existing LIVE key and secret field spellings or the canonical APCA names; conflicting canonical and alias values fail closed. This command does not install, enable, or invoke an automatic scheduler. Without a stop flag a run lasts 10 minutes. Use `npm run live -- --stop-at=12:00` to stop new entries at 12:00 Eastern; open trades keep their normal exits until flat, then the process exits. `npm run live:morning` runs LIVE under `supervise.mjs`: entries stop at 12:00 Eastern, a position still open at 15:45 Eastern triggers the normal persistent SELL path (or 60 seconds before an earlier session close); this does not guarantee a fill. A crashed run is restarted (same Eastern date only, up to 10 times, never after a clean exit, an operator stop, or a credential, account, lock, or manual-ownership error). A restart after 12:00 only manages existing positions. If the current session close cannot be read while a flatten deadline is configured, LIVE startup fails closed. If a previous run crashed, its trade-authority lock is reclaimed only when the same role's recorded process no longer exists.

Fill measurements retain the initial construction ask across entry replacements and record each entry fill minus that ask. Exit measurements record the first bid that latched the SELL decision and each sell fill minus that bid, along with the paired order identifiers and timestamps. Restored trades without a captured decision reference remain unknown; no value is inferred.

Local checks:

- `npm run check` runs the runtime check.
- `npm run check:providers` checks provider behavior with mocked transports.
- `npm run check:live-credentials` checks credential isolation and LIVE identity guards with in-memory fixtures.
- `npm run check:all` runs tracked JavaScript checks and the tracked bridge supervisor check.
