# PAPER consolidation, lane 4

The public bridge has a mode-free PAPER surface. `broker_reconcile` has no inputs; `broker_trade_evidence` accepts the exact V5 `tradeId` and optional bounded history coordinates. Three separately guarded manual order tools remain available with `BRIDGE_MANUAL` provenance, V5 stopped, and the shared trade-authority lock. The bridge has no LIVE route or automated V5 lifecycle/strategy control. The source and installed plugin descriptions now state these boundaries.

Trade evidence joins broker fills only by execution ID, symbol, and side. Alpaca's timestamp-prefixed activity IDs are normalized only when the suffix is a UUID. The linked autopsy includes signal selection, same-signal contract candidates, entry construction and order events, sampled quote decisions, thresholds, and actual broker fill records. Per-lot USD P&L requires exact entry and exit broker fills, local lot quantity, and `contractSize` sourced from Alpaca contract metadata. The set summary reports realized P&L to date; it calls a set complete only when all entry and exit lots reconcile, ledger and broker pages are complete, and no lot remains open. Missing inputs remain Unknown.

Post-exit windows retain `signalId`, `tradeSetId`/`entrySetId`, `tradeId`, `actionSource`, `orderId`, and `clientOrderId`. Their bid excursion summary uses only fresh, ordered sampled OPRA bids compared with the observed exit fill price. A missing price or quote leaves the excursion Unknown. This is sampled evidence, not continuous quote history.

The deterministic integration fixture is explicitly simulated. Source events pass through the production bounded trace writer, then its persisted rows and actual post-exit-processor output join the bridge autopsy. It joins a two-contract lot at a $1.00 entry and $1.25 exit with contract size 100 and yields $50 realized P&L, while checking candidate/entry/threshold lineage and sampled-bid excursion. Its saved evidence is [lane4-simulated-autopsy.json](../../telemetry/evidence/lane4-simulated-autopsy.json); it demonstrates the calculation path and is not a historical trade or fill claim.

The global legacy repository ledger contains 3,442 lines (1,029 local `FILL`, 1,020 local `EXIT`) across 19 trace files; historical account ownership is Unknown. The [retained local autopsy](../../telemetry/evidence/lane4-retained-local-autopsy.json) preserves one closed local lot and its three-lot set, signal, candidate, quote/threshold trace, and ledger arithmetic, but is not promoted to current-account broker evidence. The current account-scoped read contains 88 ledger events (48 `FILL`/`EXIT`). The [current-account autopsy](../../telemetry/evidence/lane4-current-account-autopsy.json) joins six per-lot ledger links to four unique broker activity IDs for the selected three-lot set: entry quantity 3, exit quantity 3, and gross realized-to-date P&L of -$21.00 using broker fill prices and Alpaca contract size 100. The set is not marked complete because continuity is missing. Signal/candidate/threshold traces exist in the repository-global legacy trace and align by exact signal, set, order, and execution identifiers, but the trace's account ownership is unknown; they are not represented as account-scoped telemetry. No account-scoped post-exit window exists, so actual post-exit excursion remains Unknown. No historical quote completeness is claimed. `telemetry/evidence/reconstruction.json` is a deterministic mocked broker replay, not retained live/PAPER execution evidence.
